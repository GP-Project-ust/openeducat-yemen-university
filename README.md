# جامعة يمنية متكاملة على Odoo 17 + OpenEduCat — بالعربية 🇾🇪

نظام ERP جامعي **جاهز للتشغيل بأمر واحد**: يرفع لك Odoo 17 مع وحدات
OpenEduCat Community الأربع مثبتة، بواجهة **عربية بالكامل** (يمين-يسار)،
وعملة الريال اليمني، **وقاعدة بيانات محمّلة سلفاً ببيانات جامعة يمنية
واقعية مولّدة عبر 5 سنوات أكاديمية**.

> انسخ المستودع، ارفع الحاويات، افتح المتصفح — ستجد أمامك جامعة حية:
> 5000+ طالب بأرقام قيد يمنية، 10 كليات، 24 برنامجاً، ~250 عضو هيئة
> تدريس، امتحانات وكشوف نتائج، وقبولات ورسوم دراسية.

## ماذا ستجد داخل النظام؟

بيانات **جامعة اليمن الأهلية** (اسم افتراضي قابل للتغيير) المولّدة عبر
السنوات الأكاديمية 2021/2022 حتى 2025/2026:

| البيانات | العدد التقريبي | أين تجدها في القوائم |
|---|---|---|
| السنوات والفصول الأكاديمية | 5 سنوات × فصلين | OpenEduCat ← الإعدادات الأكاديمية |
| الكليات (أقسام أب) | 10 | الأقسام |
| الأقسام العلمية + البرامج | 24 قسماً وبرنامجاً | الأقسام / البرامج |
| المواد الدراسية | ~624 مادة | المواد |
| الدفعات (كل برنامج × 5 سنوات قبول) | 120 دفعة | الدفعات |
| هيئة التدريس | ~250 عضواً | هيئة التدريس |
| الطلاب (أرقام قيد `YU21xxxxx` …) | 5000+ | الطلاب |
| سجلات القبول (بما فيها مرفوضة) | ~5500 طلب | القبولات |
| جلسات الامتحانات + الامتحانات | مئات الجلسات | الامتحانات |
| سجلات الحضور والدرجات | عشرات الآلاف | نتائج الامتحانات |
| كشوف النتائج (آخر سنة) | لكل دفعة وكل فصل | كشوف النتائج |
| دفعات الرسوم لكل طالب | ~10,000 دفعة | الرسوم |

كل الأسماء يمنية واقعية (محمد الشامي، فاطمة المقطري…)، والهواتف تبدأ
بـ `+967`، والمدن موزعة بأوزان سكانية واقعية (صنعاء، عدن، تعز…)،
والدرجات تتبع سلم التقديرات اليمني (ممتاز / جيد جداً / جيد / مقبول / راسب).

## كيف يعمل المشروع داخلياً؟

```
┌─────────────┐      ┌──────────────────────────────┐
│ PostgreSQL 16│◄─────│ Odoo 17 + OpenEduCat (صورة) │
│  university  │      │  - عربية RTL + ريال يمني     │
└─────────────┘      │  - قاعدة جاهزة من db_dumps  │
                     └──────────────────────────────┘
```

عند **أول** `docker compose up -d` تحدث سلسلة تلقائية:

1. **PostgreSQL** يبدأ، وينفّذ `db_init/01-restore.sh` الذي يستعيد
   `db_dumps/university.dump` — نسخة القاعدة الجاهزة المولّدة والمهيّأة
   (عربية + بيانات كاملة). تستغرق دقيقة إلى ثلاث.
2. **حاوية أودو** تنتظر جاهزية PostgreSQL (healthcheck)، يكتشف غلاف
   `entrypoint-wrapper.sh` أن الوحدات مثبتة، فيشغّل الخادم مباشرة.
3. إن كانت النسخة الجاهزة غير موجودة (حذفتَها مثلاً) فسيثبّت أودو
   الوحدات الأربع + العربية تلقائياً بدلاً منها، ثم يمكنك توليد البيانات
   بنفسك (انظر «إعادة التوليد» أدناه).

بقية التشغيلات لا تعيد أي خطوة من ذلك — الأقراص الدائمة (volumes)
تحتفظ بالبيانات.

## إعادة التوليد أو تعديل حجم البيانات

تريد توليد البيانات بنفسك (عدد طلاب مختلف مثلاً)؟

```bash
# 1) أعد كل شيء من الصفر (يحذف قاعدة البيانات والأصول)
docker compose down -v
rm -f db_dumps/university.dump          # لتعطيل النسخة الجاهزة
docker compose up -d                     # سيثبّت الوحدات (3-10 دقائق)

# 2) شغّل المولّد (التهيئة العربية + توليد جامعة كاملة)
docker compose --profile seed run --rm seeder
```

لتغيير عدد الطلاب أو الخيارات، شغّل المولّد بأي وسائط تريدها مباشرة:

```bash
docker compose exec odoo python3 /opt/scripts/bootstrap.py \
    --generate -- --preset full --target 3000 --yes

# أو المولّد مباشرة بكل خياراته:
docker compose exec odoo python3 /opt/scripts/openeducat_yemen_generator.py \
    --url http://localhost:8069 --db university \
    --user admin --password admin --preset full --yes
```

أبرز خيارات المولّد:

| الوسيطة | الوظيفة |
|---|---|
| `--preset quick` / `--preset full` | جولة سريعة (200 طالب) / جامعة كاملة (5000+) |
| `--target N` | عدد طلاب مخصص |
| `--dry-run` | اعرض الخطة والأعداد دون كتابة أي سجل |
| `--only-phases 1,2,4` | نفّذ مراحل محددة فقط |
| `--no-exams` / `--no-fees` | تخطّ مرحلة الامتحانات / الرسوم |
| `--purge --yes` | **حذف عكسي** لكل ما ولّده السكريبت (عبر سجل manifest) |

التوليد **قابل للاستئناف**: لو انقطع في منتصفه، أعد نفس الأمر وسيتخطى
الموجود ويكمل الناقص فقط — دون أي ازدواج.

## النسخ الاحتياطي والاستعادة

```bash
# نسخة احتياطية مضغوطة
docker compose exec -T db pg_dump -U odoo -Fc university \
    > backup_university_$(date +%F).dump

# الاستعادة
docker compose exec -T db psql -U odoo -c "DROP DATABASE university;" \
  && docker compose exec -T db psql -U odoo -c "CREATE DATABASE university;" \
  && docker compose exec -T db pg_restore -U odoo -d university \
       --no-owner --no-privileges < backup_university_YYYY-MM-DD.dump
```

من داخل واجهة أودو أيضاً: الإعدادات ← عام ← النسخ الاحتياطي.

## للأمان والمطورين: بروفة بلا قاعدة بيانات

قبل لمس أي نظام حقيقي، جرّب المولّد على **السيرفر الوهمي** الذي يحاكي
نماذج OpenEduCat في الذاكرة:

```bash
python3 scripts/mock_odoo_server.py 8169          # طرفية 1
python3 scripts/openeducat_yemen_generator.py \
    --url http://127.0.0.1:8169 --db mock \
    --user admin --password admin --preset quick --yes   # طرفية 2
```

ثم جرّب دورة الأمان كاملة: `--purge --yes` يحذف كل ما وُلّد بالعكس
(عبر ملف `openeducat_manifest.json` الذي يسجل كل معرّف أُنشئ).

**فلسفة المولّد**: كل الكتابات تمر عبر واجهة XML-RPC الرسمية لأودو —
أي عبر طبقة ORM نفسها التي تستخدمها الواجهة الرسمية — دون أي SQL
مباشر إطلاقاً. التفاصيل الكاملة في `docs/openeducat-yemen-guide.pdf`.

## استكشاف الأخطاء

| المشكلة | السبب والحل |
|---|---|
| المتصفح: «This site can't be reached» | أودو لم يكتمل بعد — انتظر ثم تحقق: `docker compose logs -f odoo` |
| صفحة تسجيل الدخول لا تفتح بعد 10 دقائق | راجع السجلات؛ إن رأيت خطأ استعادة النسخة الجاهزة فأعد التوليد: `docker compose down -v && rm db_dumps/university.dump && docker compose up -d` ثم `docker compose --profile seed run --rm seeder` |
| أريد واجهة إنجليزية مؤقتاً | من قائمة المستخدم (أعلى اليمين) ← اللغة ← English |
| تغيير كلمة مرور admin | الإعدادات ← المستخدمون ← admin ← كلمة المرور (وثّقها في `.env` إن استخدمت المولّد لاحقاً) |
| المنفذ 8069 مشغول | غيّر `ODOO_PORT` في `.env` ثم `docker compose up -d` |
| إعادة ضبط كاملة | `docker compose down -v && docker compose up -d --build` |
| أريد مدير قواعد البيانات | احذف `list_db = False` من `config/odoo.conf` ثم أعد التشغيل |
